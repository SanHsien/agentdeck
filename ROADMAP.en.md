## Maintenance

The fork tracks upstream `aqua5230/usage`: the "upstream update check" workflow runs daily at 02:00 UTC, compares against `last_reviewed` in `docs/UPSTREAM.md`, and opens or updates an issue when there are new items. Each entry is judged and then either adopted (hand-ported with tests, advancing `last_merged` and `last_reviewed`) or not adopted (advance only `last_reviewed`, add a row and reason to the Skipped table). A failure means upstream has unreviewed items, not that the tool is broken. Dependency freshness is checked on the 1st of each month; releases follow SemVer (D-05). To check the current state: `gh issue list -R SanHsien/agentdeck`, `gh api repos/SanHsien/agentdeck/dependabot/alerts?state=open`, `gh run list -R SanHsien/agentdeck -b main -L 8`.
